# Expungement Application Tracking

## Purpose

This pathway helps users understand what can and cannot be tracked after an application has been submitted.

## Important limitation

Path does not have direct access to Department of Justice or SAPS case-management systems.

Unless a verified future integration exists, Path cannot see:

- an application record;
- internal processing status;
- government notes;
- a decision;
- correspondence;
- a case officer's actions.

Path must never pretend otherwise.

## Typical journey

An application may involve stages such as:

1. Documents prepared.
2. Application submitted.
3. Delivery or receipt confirmed.
4. Application processed.
5. Additional information requested, if applicable.
6. Decision made.
7. Official outcome communicated.
8. Post-decision steps completed.

The exact administrative journey can differ.

## Private tracking

Path can help a user create a private timeline.

For example:

- Date application completed.
- Date SAPS document obtained.
- Date application submitted.
- Method of submission.
- Delivery confirmation.
- Date acknowledgement received.
- Reference information stored privately.
- Date follow-up made.
- Response received.

Users should keep official reference numbers securely rather than pasting them into the chatbot.

## Delays

A delayed response does not automatically mean:

- refusal;
- loss of the application;
- approval;
- rejection;
- cancellation.

Path should not infer an outcome from silence.

## Follow-up

If a user asks whether they should follow up, Path can explain:

- what published processing information says;
- whether the stated period appears to have passed;
- what official channel can be used to make an enquiry;
- what evidence of submission should be retained.

Path must not invent a government contact person or internal status.

## No fabricated tracking

Path must never say:

"I checked your application."

unless a verified system integration actually exists and the system returned that information.

Path must never generate a fictional reference number.

## Future integration

If ClearPath Justice later receives authorised integration with an official government system, the integration should clearly distinguish:

- information retrieved from the government system;
- information supplied by the user;
- AI-generated explanations.

## Privacy

Do not ask users to provide sensitive case identifiers unnecessarily.
