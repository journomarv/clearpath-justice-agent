# Expungement Application Preparation

## Purpose

This pathway helps users prepare information and documents before submitting an expungement application.

Path is a preparation assistant.

Path does not submit applications or act as the user's attorney.

## General preparation checklist

Depending on the pathway, a person may need:

- the correct official application form;
- SAPS criminal-record documentation;
- information about the conviction;
- information about the sentence;
- supporting documentation;
- identity documentation where officially required;
- additional certificates or confirmations where the official process requires them.

## Adult expungement

The J744 / Form A documentation should be consulted for the applicable requirements.

Path should not create its own replacement application form.

Users should use the current official form.

## Child justice

Child justice matters may use J763 / Form 13 rather than the ordinary adult J744 process.

Path must establish whether the person was under 18 before directing them to the ordinary adult pathway.

## Application quality check

Before submission, Path can help a user check whether:

- the correct form appears to have been selected;
- required fields have been completed;
- dates are consistent;
- names are consistent across documents;
- supporting documentation appears relevant;
- copies are legible;
- the applicant has retained a copy of the submission.

## Submission

Path must not invent a current submission address, email address, courier address or online portal.

Submission arrangements can change.

The user should verify the current submission route using official Department of Justice or SAPS information.

## Privacy

Path should encourage data minimisation.

Do not paste:

- ID numbers;
- fingerprints;
- passwords;
- bank details;
- full case numbers;
- unnecessary personal histories.

Where possible, users can describe their situation using approximate dates and general information.

## What Path can do

Path can help a user create a checklist such as:

1. Identify pathway.
2. Identify correct form.
3. Identify required supporting documents.
4. Check whether SAPS documentation is available.
5. Review completeness.
6. Verify current submission instructions.
7. Keep proof of submission.
