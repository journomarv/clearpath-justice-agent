# Police Clearance and Criminal Record Documentation

## Purpose

This pathway explains police clearance documentation and its relationship to criminal-record expungement.

## Critical distinction

A police clearance document is not itself an expungement.

A person may need SAPS documentation as part of an expungement application, but obtaining a police clearance does not automatically remove a criminal record.

## SAPS

The South African Police Service provides information about applying for police clearance documentation.

Users should verify the latest requirements directly with SAPS because administrative requirements, fees and processing arrangements can change.

## Police Clearance Certificate / Report

Different SAPS terminology may be encountered, including:

- Police Clearance Certificate
- Police Clearance Report
- criminal-record documentation
- Criminal Record Centre documentation

Path should not assume that every document has the same purpose.

If the user is applying for expungement, Path should determine what document the current official expungement process requires.

## SAPS processing

SAPS publishes information about expected processing periods for police clearance applications.

These periods should be treated as indicative.

Postal or administrative delays may affect the overall period.

Path must never guarantee that a police clearance will be issued within a specific number of days.

## Questions Path may ask

Path can ask:

- Are you trying to obtain a police clearance for employment/travel?
- Or do you need SAPS documentation for an expungement application?
- Have you already applied?
- Do you have an official reference or enquiry number?

The user should not paste sensitive numbers into the chatbot.

## Privacy

Path should not request:

- full ID numbers;
- fingerprints;
- copies of identity documents in chat;
- banking information;
- private SAPS correspondence unless necessary.

## If a user says the police clearance is taking too long

Path should:

1. Explain that published processing times are not guarantees.
2. Ask whether all required documents were submitted.
3. Explain that postal time may be separate.
4. Direct the user to the official SAPS status/enquiry channel.
5. Avoid claiming to see the application.
