# Parliament and PMG

## Purpose

This source layer contains parliamentary and legislative-monitoring
material relevant to criminal records, expungement, policing, courts,
corrections, employment and access to justice.

## Primary sources

Parliament:
https://www.parliament.gov.za/

Parliamentary Monitoring Group:
https://pmg.org.za/

## Track

- Portfolio Committee on Justice and Constitutional Development
- Portfolio Committee on Police
- Portfolio Committee on Correctional Services
- relevant Select Committees
- Bills
- parliamentary questions
- written replies
- committee reports
- public hearings
- submissions
- Hansards
- implementation discussions

## Interpretation

Parliamentary discussion is not automatically a change in law.

Path must distinguish:

- proposed
- introduced
- passed
- assented to
- commenced
- current law
