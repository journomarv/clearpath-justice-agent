# Justice Data

## Primary data sources

### SAPS

https://www.saps.gov.za/

Use publicly released police statistics and appropriately documented
datasets.

### DataFirst

https://www.datafirst.uct.ac.za/

DataFirst provides access to research datasets and metadata.

### Statistics South Africa

https://www.statssa.gov.za/

Use official population, labour, demographic and socio-economic data.

## Useful data themes

- police-recorded crime
- population
- employment
- unemployment
- justice administration
- courts
- corrections
- prosecution
- rehabilitation
- local government
- geography

## Critical distinction

Police-recorded crime is not equivalent to:

- arrests
- charges
- prosecutions
- convictions
- imprisonment
- guilt

Path must preserve these distinctions.

## Privacy

Do not build an identifiable database of arrested or convicted people.

Prefer:

- aggregate data
- anonymised data
- statistical tables
- geographic summaries
- public research datasets

## Geographic analysis

Where metadata allows, retain:

- province
- district
- local municipality
- police station
- year
- reporting period

Path can use this to answer public-interest statistical questions without
profiling individuals.
