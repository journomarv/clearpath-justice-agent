# ClearPath Justice Design System

## Identity

ClearPath Justice is the primary product identity.

Path is its conversational justice assistant.

## Theme

Calm civic-professional design with navy structure, green action, restrained gold accents, bright surfaces and generous spacing.

## Color roles

- Primary structure: navy
- Primary action: green
- Accent: gold
- Application background: light neutral
- Surface: white
- Primary text: near-black
- Secondary text: slate gray
- Borders: pale blue-gray

## Typography

Inter with a system sans-serif fallback.

Use readable body sizing and compact but generous headings.

## Composition

The main experience is conversation-first.

Navigation and supporting features should frame the conversation rather than compete with it.

## Components

Use semantic:
- buttons
- inputs
- cards
- navigation items
- message bubbles
- source references
- next-action panels

Components should use semantic design tokens.

## Interaction

Use restrained 140–200ms ease-out transitions.

Provide visible keyboard focus.

Never depend on hover.

## Accessibility

Maintain strong foreground/background contrast, semantic HTML, keyboard navigation, touch-friendly controls and reduced-motion support.

## Content tone

Clear, respectful and non-judgmental.

Path explains and assists; it does not adjudicate.

## Anti-patterns

No:
- AI neon gradients
- fake legal authority
- decorative legal clichés
- excessive cards
- excessive animation
- generic chatbot styling
